# Security reporting

Please do not post wallet secrets or exploit details that expose users in public issues.

Use the repository’s private vulnerability reporting feature if enabled, or contact the repository owner through a private GitHub channel. If no private route is available, open a minimal issue requesting a private contact without disclosing the vulnerability itself.

Lynk is an additional phishing-defense layer, not a transaction firewall. See [the threat model](docs/RESEARCH.md) and [privacy policy](PRIVACY.md) before deploying it to users.
